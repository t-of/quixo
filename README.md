# quixo — 5マスの盤をずらして5つ並べる対戦パズル

外周のキューブを押し込んで、縦横斜めに5つ揃えたら勝ち

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/quixo/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

5×5・25 個のキューブ（無地 / ○ / ×）を使う 2 人用のボードゲーム。

1. 外周（16マス）から「無地か自分の印」のキューブをタップで選ぶ。
2. 押し込める端（もう一方のタップで候補が光る）をタップすると、自分の印にしたキューブをそこから押し込み、間のキューブが 1 つずつずれる。取った場所と同じ位置には戻せない。
3. 縦・横・斜めのどれかに自分の印が 5 個並べば勝ち。1 手で両者の列ができたときは、手番側の負け。同じ局面が 3 回現れたら引き分け。

「CPU と対戦」（先手・後手を選べる）と「2人で対戦（1台で交互）」から選べる。試作のため効果音・設定・共有の演出・記録はなし。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
